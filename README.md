## Conocimientos técnicos

### Sistemas operativos y administración

- **Windows cliente:** instalación y configuración de Windows 11, usuarios locales y conexión de equipos a un dominio.
- **Windows Server 2022:** Active Directory DS, unidades organizativas, usuarios, grupos de seguridad y delegación de permisos.
- **Directivas y acceso:** GPO, políticas granulares de contraseña, carpetas compartidas y asignación de unidades de red.
- **Linux:** administración de Ubuntu Server, usuarios, grupos, permisos, procesos y servicios desde la terminal.
- **Almacenamiento y recuperación:** particiones, sistemas de archivos, RAID 1, copias de seguridad y restauración de objetos del directorio en prácticas académicas.
- **Diagnóstico y seguridad:** revisión de reglas de firewall, registros de eventos y registros de servicios SSH y Apache.

### Redes y servicios

- **Direccionamiento IPv4:** configuración de IP, máscara, gateway y DNS en equipos Windows y Linux.
- **Subnetting:** cálculo de red, broadcast y rango de hosts; elección de prefijos y dimensionamiento de redes locales.
- **Fundamentos de comunicación:** Ethernet, direcciones MAC, ARP, ICMP y diferencia entre conectividad de enlace y conectividad IP.
- **Servicios de directorio:** relación entre DNS, LDAP y Kerberos en Active Directory y Samba AD DC.
- **Comprobación de conectividad:** uso de `ping`, consulta de interfaces y puertos, y revisión de la configuración del cliente y del servidor.
- **Documentación de redes:** tablas de direccionamiento, esquemas de LAN y explicación de las decisiones de configuración.

### Virtualización y laboratorio

- **VirtualBox:** creación y configuración de máquinas virtuales Windows y Ubuntu.
- **Redes virtuales:** NAT, red interna y adaptador de solo anfitrión según el escenario de la práctica.
- **Entornos cliente-servidor:** comunicación entre varias máquinas y configuración de interfaces para separar la red de laboratorio del acceso a paquetes.

### Programación y scripting

- **Python · Algorítmica:** diseño, implementación y comprobación de algoritmos; recursividad, divide y vencerás, ordenación y tratamiento de secuencias.
- **Java · Orientación a objetos:** clases, composición, herencia, polimorfismo, colecciones y aplicaciones de consola.
- **C++ · Estructuras de datos:** plantillas, colas FIFO, nodos enlazados, árboles binarios de búsqueda y gestión de memoria.
- **PowerShell:** consultas y tareas de administración de Active Directory, tratamiento de CSV y alta de usuarios.

### Bases de datos y herramientas

- Diseño de bases de datos relacionales y consultas SQL con **MySQL y Oracle**.
- Bases de **HTML y CSS**, documentación técnica y uso de **Microsoft 365**.
- Pruebas de programación y mantenimiento de los proyectos publicados con **Git y GitHub**.

## Laboratorios de sistemas y redes

**Dominio Windows y gestión de identidades.** Instalación de servidor y cliente, organización de usuarios y grupos, delegación de tareas y uso de PowerShell. Las prácticas también incluyen GPO, políticas de contraseña, recursos compartidos y comprobación de las directivas recibidas por el cliente.

**Mantenimiento de Active Directory.** Trabajo con un segundo controlador, consultas de roles FSMO, auditoría de cuentas, papelera del directorio y copias del estado del sistema. La documentación recoge las incidencias y los límites de las comprobaciones realizadas.

**Dominio Linux con Samba AD DC.** Configuración de red en Ubuntu Server, provisionamiento del directorio, resolución DNS, comprobaciones de Kerberos y unión de un cliente Windows al dominio.

**Diseño de redes IPv4.** Cálculos de subredes, elección de prefijos y diseño de LAN independientes. Las tablas y los esquemas explican qué direcciones pueden asignarse y cuándo hace falta un router para comunicar redes distintas.
