## Sobre mí

En mis prácticas trabajo con Windows Server, Linux, servicios de directorio y direccionamiento IPv4. La programación me ayuda a entender cómo se organizan los datos, cómo se procesan tareas y qué costes tienen las operaciones de un programa.

Este perfil reúne los trabajos que mejor representan esa formación, con instrucciones para revisar o ejecutar cada proyecto y comprobaciones acordes a su alcance.

## Habilidades en práctica

**Sistemas y redes**

- Windows Server 2022, Windows 11 y Ubuntu Server.
- Active Directory: OU, grupos, delegación, GPO y mantenimiento del directorio.
- Samba AD DC, DNS y Kerberos.
- PowerShell para consultas y tareas de administración.
- VirtualBox y redes de laboratorio.
- IPv4, subnetting y planes de direccionamiento.

**Programación**

- **Python:** tratamiento de cadenas, compresión RLE, ordenación y pruebas con `unittest`.
- **Java:** orientación a objetos, herencia, polimorfismo, colecciones y aplicaciones de consola.
- **C++:** plantillas, nodos enlazados, colas FIFO, árboles binarios de búsqueda y gestión de memoria.
